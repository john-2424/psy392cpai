\section{Agent Hyperparameters}
\label{app:hyperparams}

All three agents sit on top of the same convolutional encoder: two 3$\times$3 conv layers (channels $3\rightarrow 16\rightarrow 32$) with ReLU activations, followed by a linear layer that flattens the feature map down to a \texttt{feature\_dim}-sized embedding. \section{Reproducing the Experiments}
\label{app:reproduce}

Everything below runs from \texttt{project/} with \texttt{PYTHONPATH=.} exported:

\begin{verbatim}
# (1) Stable + zero-shot + adaptation for each agent (3 seeds each)
python scripts/train_ppo.py      # ~20 min
python scripts/train_sr.py       # ~60 min (500 eps, v3)
python scripts/train_replay.py   # ~60 min

# (2) SR phi-normalization ablation
python scripts/train_sr_no_norm.py  # ~5 min

# (3) Representation probe (reads best.pt for each agent x seed)
python scripts/probe_representations.py  # ~30 s

# (4) Figures + summary + adaptation metrics
jupyter nbconvert --to notebook --execute notebooks/analysis.ipynb --inplace
\end{verbatim}

Those four steps populate \texttt{results/csv/} with the training / evaluation / adaptation / probe CSVs, write every figure referenced in the paper into \texttt{results/figures/}, and produce \texttt{results/summary\_table.csv} (Table~\ref{tab:summary}), \texttt{results/adaptation\_metrics.csv} (Tables~\ref{tab:auc} and \ref{tab:per-seed-auc}), and \texttt{results/csv/probe\_results.csv} (Tables~\ref{tab:probe} and \ref{tab:probe-per-seed}).
